## Verdict summary (one line each)
- H and I are real, separate SDSF panels; DA, PR, INIT also real (repo aliases/"not available" are simplifications).
- SE != SJ: SE = ISPF edit of output data sets, SJ = ISPF edit of job JCL; X = print, not browse.
- SJ/SE edits: IBM says changes "are not saved" and the JCL can be resubmitted; nothing says the original PDS member is updated — repo's "saving writes back the member" is contradicted.
- PREFIX: bare name = exact match; trailing `*` = prefix. Repo's startsWith-for-bare-name is wrong. IBM default PREFIX and OWNER = NONE (all), site-configurable; only H is user-ID-limited by default.
- ST/JDS column layouts largely correct; "Date" is not an ST column title.
- LOG: real = SYSLOG/OPERLOG console log; repo is a summary (documented simplification).
- ISPF entry: `S` (or 13.14 / site option) is documented; `TSO SDSF` documented; bare `SDSF` needs command-table entry; `SD` undocumented.
- Repo resources: share-lab URL unreachable; ispf-edit link is a 2006 z/OS 1.8 copy on a university host; ISPF UG link is 3.1 (3.2 exists).
