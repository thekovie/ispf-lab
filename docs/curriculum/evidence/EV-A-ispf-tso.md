## Summary of verdicts

CONTRADICTS (fix in repo):
- Edit SUBMIT "submits the data set on disk, unsaved changes not submitted" (explain.ts:400, editor.ts:319). IBM: submits "the member or data set you are editing", with line/label/X/NX ranges. Doc silent on unsaved changes. The on-disk behaviour is documented only for **Browse SUBMIT**.
- "No undo in classic ISPF Edit" (explain.ts:197). UNDO and SETUNDO exist.
- "CAPS OFF restores the default" / docs "Defaults: CAPS OFF, NUMBER OFF". CAPS is auto-set from the data. The example ZDEFAULT profile has CAPS ON, NUMBER ON, STATS ON, AUTOSAVE ON, RECOVERY OFF.
- "BNDS on its own shows an editable =BNDS> line" (primary command BNDS/BOUNDS with no operands RESETS to default; the display form is the line command). BOUNDS is not in =PROF> lines; the profile shows five =PROF> lines plus separate =TABS> =MASK> =BNDS> =COLS>, and =BNDS> only if non-default.
- "ISPF never pops up dialog boxes" (Settings: "Long message in pop-up", pop-up windows throughout).
- Option 0 "Default scroll amount" (not an Option 0 field; it is the per-panel Scroll field).
- "3.4 typed still goes through Utilities, so two PF3s" (doc: typing 3.4 bypasses the second menu; the page does not state PF3 count outright).
- "MODIFIED" on the Edit status line is not documented (docs show ==CHG> flags and "DATA CHANGED-SAVE/CANCEL").

PARTIAL (reword): RECOVERY "journals keystrokes" (records interactions/changes; UNDO no longer needs it); FIND/CHANGE quoting (also commas, keywords); Dsname Level "name prefix" (qualifier-based; 3.2 has Include Additional Qualifiers checkbox; off = exact match); "up to 8" screens (default 8, max 32); second PF1 goes to tutorial; X on option line; statistics "audit trail" (overstated, mod level bumps on first change); IKJ56650I field order; IKJ56228I wording.

SUPPORTS: line commands; RESET/FLIP/LOCATE/COLS/STATS/HEX/NUMBER; CANCEL/END/SAVE/AUTOSAVE semantics (AUTOSAVE default ON only as an example/site-config); directory blocks > 0 = PO; 3.1/3.2/3.3 option sets; G = reset member statistics; `;` stacking; jump `=`; RETURN; RETRIEVE; Browse has no prefix area; IKJ56250I, IKJ58503I, IKJ56500I, IKJ56709I; `SUBMIT *` valid (not in EDIT mode); unquoted names get prefix.

UNRESOLVED / DOESN'T ADDRESS: default descriptive qualifier CNTL for SUBMIT; SAVE of empty new member; PF3 count for typed 3.4 (implied only); PDSE alias claims (no repo text found).
