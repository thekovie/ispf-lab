# Simulator gap matrix (Phase 0, Deliverable 5)

Part of the [Phase 0 audit](phase-0-audit.md). Baseline commit `e97a91b`. Audit date 2026-10-14.

**Method.** Each row compares the simulator code (read, not assumed) with IBM documentation verified in [verified-sources.md](verified-sources.md) and the evidence appendices (`EV-A`, `EV-B`, `EV-C`). Code references are `path:line` at the baseline commit. Tests were **run** (`pnpm check`: typecheck, lint and 231 tests in 15 files all pass) but a passing test establishes internal consistency only. No runtime reproduction of the scenario-isolation items was performed (code-read only; reproduction is part of the first remediation milestone).

**Capability classes:** FULLY SUPPORTED · PARTIALLY SUPPORTED · SIMULATED WITH DOCUMENTED LIMITATIONS · UNSUPPORTED · REQUIRES TECHNICAL CORRECTION · NOT VERIFIED.

**Priority:** P0 essential (correctness or assessment integrity), P1 high, P2 medium, P3 optional. "Affected lessons" use lesson numbers; where only the area (not a specific lesson) is known the cell says so.
